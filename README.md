# Math-Game
A console-based math quiz game developed in C++.
The game generates random arithmetic questions based on the selected difficulty level and operation type, then evaluates the player's answers and displays the final result.

Project Overview

MathGame is a C++ console application designed to practice fundamental programming concepts through an interactive mathematical quiz.

Before starting the game, the player can choose:

- The number of questions.
- The difficulty level.
- The arithmetic operation.

The game then generates questions randomly, checks each answer, and provides a final performance summary.

Features

- Randomly generated math questions.
- Three difficulty levels:
  - Easy
  - Medium
  - Hard
- Mixed difficulty mode.
- Four arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Mixed operation mode.
- Immediate feedback after each answer.
- Displays the correct answer when the player's answer is incorrect.
- Counts correct and incorrect answers.
- Displays a final Pass/Fail result.
- Option to play the game again.
- Different screen colors for correct and incorrect answers.

 How to Play

When the program starts, the player is asked to:

1. Choose the number of questions.
2. Select the question difficulty.
3. Select the arithmetic operation.
4. Answer each generated question.
5. View the result after each answer.
6. View the final quiz summary.

At the end of the quiz, the player can choose whether to play again.

 Final Results

After completing the quiz, the program displays:

- Final Pass/Fail result.
- Number of questions.
- Selected question level.
- Selected operation type.
- Number of correct answers.
- Number of incorrect answers.
